# EddieAI

Android AI assistant inspired by **Eddie** from Lab Rats.

### Concept
- Clean interface focused on the animated face (no chat bubbles)
- User can talk by voice **or** type text
- Eddie always responds with **voice only** (text from Eddie is never shown)
- User messages are processed silently (not displayed on screen)
- Sarcastic, dramatic and helpful personality
- Face changes expression based on the tone of the response
- Lab-style background

### Interaction Flow
1. User speaks or types
2. Message is sent to Grok (xAI)
3. Eddie thinks and answers with voice
4. Face reacts with the correct expression

### Tech Stack
- Kotlin + Jetpack Compose
- Grok API (xAI)
- Android Speech-to-Text
- Android Text-to-Speech
- Animated Vector / Lottie for expressions

### Status
Project under active development.

---

**Goal:** Create the closest possible experience to talking with Eddie, while keeping everything original and clean.
